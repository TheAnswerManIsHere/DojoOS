# First-build constraints

1. **Separate Reserved VMs:** Replit publishes a project's artifacts together as one deployment, not as two independent Reserved VM deployments. The repository has separate web and worker commands, but the worker needs a second Repl for a separate VM. A second Repl does not automatically inherit the first project's managed production database. Both processes must be given access to the same production database before the requested topology can run; this has not been configured or published here.
2. **External configuration:** Real magic-link email delivery and private Backblaze B2 uploads cannot run until the two account addresses, mail sender/SMTP service, public app origin, and S3 bucket/endpoint/credentials are supplied. No fake mail, media, accounts, or storage fallback is included.
3. **Sign-in exceptions:** An unauthenticated user must be able to request and consume a magic link and load the sign-in screen/assets. These are necessarily reachable without a prior session; no library, feedback, or media data is public.
4. **Existing scaffold:** The project already included an API-server and mockup-sandbox artifact before DojoOS. The product's requested `web`, `worker`, and `shared` packages exist alongside that pre-existing scaffold rather than deleting unrelated workspace artifacts without consent. The old API-server has no product routes.
