# DojoOS — product direction

DojoOS replaces Kajabi for Bodywork Dojo one module at a time, starting
with the one thing Kajabi cannot do: a video-production pipeline built
around how Jared shoots. It is optimised so that Jared pays nobody to edit,
publish or operate it, which makes ease of use the product requirement.

Module order and boundaries: [`product-brief.md`](product-brief.md).
